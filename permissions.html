จัดการสิทธิ์ผู้ใช้

กำหนดว่าใครอยู่ฝ่ายไหน และอนุญาตให้ทำงานในฝ่ายนั้นได้หรือไม่

ภาพรวมฝ่ายวิชาการฝ่ายการเงินฝ่ายบุคคลบริหารทั่วไปจัดการสิทธิ์ผู้ใช้ส่งมอบงานครูที่ออกข้อมูลส่วนตัว
กำลังตรวจสอบสิทธิ์…
สิทธิ์ระดับฝ่ายทำงานอย่างไร ผู้ที่ได้รับอนุญาตในฝ่ายใด จะทำงานในหน้าของฝ่ายนั้นได้เหมือน admin — เพิ่มและแก้ไขได้ แต่ลบไม่ได้ (การลบสงวนไว้ที่ admin เท่านั้น) · ถ้าตั้งเป็น “อยู่ฝ่ายนี้ แต่ยังไม่อนุญาต” จะยังทำอะไรไม่ได้
คนหนึ่งอยู่ได้หลายฝ่ายพร้อมกัน · การเลื่อนใครเป็น admin ยังต้องทำผ่าน Supabase (SQL) เหมือนเดิม

— ไม่อยู่ฝ่ายนี้ · รอ = อยู่ฝ่ายนี้ ยังไม่อนุญาต · อนุญาต = ทำงานในฝ่ายนี้ได้
